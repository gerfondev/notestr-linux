# Notestr Linux 3.5

- Ajout d’un bouton **Copier** dans les champs **Code Block** : copie du code
  dans le presse-papiers Linux en conservant espaces et retours à la ligne.
- Création d’un fichier **AppImage amd64** avec Python, GTK4/libadwaita et WebKitGTK.
- Numérotation commune **3.5** pour le code, le paquet Python et l’AppImage.

L’AppImage cible Ubuntu 24.04 / Zorin OS 18, avec glibc 2.39 ou ultérieure.
Il a été testé sous Zorin OS 18.1 amd64. Les autres distributions n’ont pas été
validées. Une session graphique et le trousseau Secret Service restent fournis
par le système. Sans FUSE, utiliser `--appimage-extract-and-run`.

Validation : 34 tests automatisés réussis, tests graphiques GTK/WebKit,
presse-papiers et export PDF embarqué réussis. Audit des sources et du paquet :
aucun chemin personnel de l’utilisateur détecté ; mentions de licence conservées.

L’historique 3.1 et 3.4 reste disponible. Les anciennes numérotations Python
`0.3.x` correspondaient aux éditions affichées `3.x`.

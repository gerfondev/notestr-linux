# Notestr Linux 3.5.1

- Correction de l’actualisation automatique des notes à l’ouverture du compte :
  le chargement de l’éditeur visuel ne bloque plus la récupération des notes.
- Mise à jour des dépendances Python, notamment cryptography 50.0.1,
  Pillow 12.3.0 et markdown-it-py 4.2.0.
- Bibliothèques Kerberos de l’AppImage mises à jour vers
  `1.20.1-6ubuntu2.10`, sans modifier le système hôte lors de la construction.
- Suppression du nom du compte de construction dans les métadonnées de
  l’archive source Python ; inventaire des bibliothèques natives embarquées.

Validation : 37 tests automatisés réussis, tests graphiques GTK/WebKit et
export PDF embarqué réussis. Audit PyPI des 41 dépendances Python : aucune
vulnérabilité connue signalée au 22 septembre 2026. Les 181 paquets système
recensés dans l’image ne présentent aucune mise à jour en attente dans les
index Ubuntu/Zorin consultés ce jour.

Les sources, l’AppImage extraite, le wheel et l’archive source ont été contrôlés :
aucun chemin personnel de l’utilisateur, note, configuration de compte ou secret
utilisateur détecté. Les licences, exemples publics et chaînes techniques des
bibliothèques tierces sont conservés. Les détails et limites de l’audit figurent
dans `SECURITY.md`.

L’AppImage cible Ubuntu 24.04 / Zorin OS 18 amd64, avec glibc 2.39 ou ultérieure.
Tests réalisés sous Zorin OS 18.1. Sans FUSE, utiliser
`--appimage-extract-and-run`. L’historique des versions précédentes est conservé.

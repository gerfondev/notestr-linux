# Notestr 4.0 — Android et Linux

- Ajout de dossiers nommés pour classer les notes, avec création, renommage et suppression.
- La suppression d’un dossier demande confirmation et déplace ses notes vers « Sans dossier » sans les effacer.
- Les notes épinglées restent en tête de la liste et apparaissent aussi dans leur dossier.
- Les dossiers sont triés par ordre alphabétique ; « Sans dossier » reste à la fin.
- Le dossier d’une note est indiqué dans la liste sur Android et Linux.
- Mises à jour de sécurité Linux : `websockets` 17.4 et `cryptography` 50.0.2. La mise à jour Android conserve la base SDK/API qualifiée ; les bibliothèques récentes nécessitant une migration AGP/SDK sont documentées dans la revue.
- Numéros de version Android et Linux alignés sur 4.0.

Android : versionCode 73. Linux x86_64 : AppImage, wheel Python et archive source. Les contrôles de sécurité et de confidentialité, ainsi que leurs limites, sont consignés dans `SECURITY-REVIEW.md`.

# Notestr Linux 3.7.1

## Correction

Le copier-coller d’une adresse web dans le champ **URL** de « Insérer un lien » fonctionne désormais correctement. Le texte collé reste dans le champ choisi, sans insertion dans la note ni modification intempestive de sa mise en page. Le champ **Texte du lien** bénéficie de la même correction. Annuler conserve la note ; valider insère le lien à l’endroit choisi.

## Sécurité et confidentialité

Contrôles des dépendances, des sources et des paquets renouvelés. Les vérifications sont ciblées et ne constituent pas un audit exhaustif. Les anciennes métadonnées d’auteur déjà publiques sont conservées dans l’historique Git. TOAST UI reste archivé ; cette réserve demeure documentée.

AppImage x86_64 avec WebKitGTK 2.54.0 et libgbm1 25.2.8-0ubuntu0.24.04.4. Le contrôle élargi des bibliothèques natives identifie des avis non corrigés supplémentaires, analysés dans SECURITY-REVIEW.md et le rapport d’exposition. Les restrictions de contenu réduisent certaines expositions sans garantir leur absence. Fermer l’ancienne application avant de lancer la nouvelle AppImage. Paquets Python également disponibles.

Les fichiers distribués sont accompagnés de leurs empreintes SHA-256. Voir SECURITY-REVIEW.md pour les validations et limites.
